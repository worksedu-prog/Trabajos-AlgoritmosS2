Analisis de secuencia, caso: Insertion sort

/* Insertion Sort */
void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}


1.¿Qué es n en esa secuencia?

Rta: La complejidad de la función consta de O(n^{2}) siendo n el tamaño o la lónguitud del arreglo

2.¿Cuantas veces se ejecuta el proceso si se duplican los datos?

Rta: Dependera del caso que se tome como el mejor o el peor:

Peor caso: La complejidad sseguira siendo O(n^{2}) al duplicar los datos, pero su tiempo de ejecución sera las operaciones multiplicadas por 4
El mejor caso: La lista ya estara ordenada siendo una complejidad de O(2n) siendo constante, ejecutandose solo 2 veces

Se invocan 0 procesos pues no cuenta con metodos
