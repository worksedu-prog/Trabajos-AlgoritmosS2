1. Subir cambios de Visual Studio Code a la web ( PC ➔ GitHub)

git add . — Prepara y selecciona todos los archivos nuevos o modificados.

git status — Verificar que todo se subio correctamente

git commit -m "Mensaje descriptivo de lo que subes" — Empaqueta los cambios localmente con una nota.

git push — Envía todo definitivamente a tu repositorio en GitHub.


1.1 En caso de que marque el codigo como M

git add .

git status

git commit -m "blah blah blah"

git push origin main

git status
